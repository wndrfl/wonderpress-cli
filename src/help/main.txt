wonderpress — build WordPress themes from manifests

USAGE
  wonderpress <command> [subcommand] [options]

GLOBAL OPTIONS
  --dir <path>             Environment root (default: detected project root)
  --theme <name>           Target a theme by slug
  --env <host|wp-env>      Backend (init records this in .wonderpressrc)
  --format json            Machine-readable { ok, data, error } envelope
  -h, --help               Help for this command

ENVIRONMENT
  init          Build a new environment: WordPress, the theme, and Static Kit
  server        Start (or `server stop`) the local development environment
  static        Compile (or `--watch`) the theme's Static Kit assets
  destroy       Tear the environment down, keeping the theme and its files
  lint          Run phpcs and manifest drift over the theme
  acf           Install ACF or ACF PRO from the official distribution
  version       Print the installed version
  agents        Write AGENTS.md from conventions and manifests
  mcp           MCP stdio server (same operations, agent client)

AUTHORING
  partial       Reusable render primitives — the unit of markup in a theme
  block         Editor wrappers that expose a partial in Gutenberg
  template      Page templates — create, list, and remove
  readme        Generate a project README

Run `wonderpress <command> help` for detail. Start with
`wonderpress partial help` if you are new; almost everything begins there.
Requires Node.js 24+, WP-CLI, PHP, and Composer.
