wonderpress lint — phpcs, partial drift, and page templates

Runs PHPCS against the Wonderpress coding standards, `partial check-drift`,
and `template validate` on the active theme (or `--theme` / the only theme
on disk).

--fix / -f runs phpcbf on lightweight PHPCS issues. It does not repair
manifest drift — use `wonderpress partial sync` for that — and it does not
edit page-template manifests or PHP.

Partial drift uses the sync states of `partial check-drift`: a partial in
conflict (hand edits inside generated output) or whose generated files no
longer match its manifest is an error; a pending partial whose files still
match (for example, no sync lock yet) is a warning and does not fail lint.
See `wonderpress partial help` (SYNC STATES).

--axe and --budget are reserved and currently skipped.

OPTIONS
  -f, --fix                Auto-fix lightweight phpcs issues (phpcbf)
  --theme <name>           Theme slug
  --dir <path>             Environment root
  --format json            Machine-readable envelope
  --axe                    Reserved (currently skipped)
  --budget                 Reserved (currently skipped)

EXIT CODES
  0                        Clean
  1                        phpcs, partial drift (conflict, or files out of
                           step with the manifest), or page-template failure
  2                        Usage (for example, which theme is ambiguous)

EXAMPLES
  wonderpress lint
  wonderpress lint --fix
  wonderpress lint --format json
